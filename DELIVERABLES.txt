🚀 HOW TO USE THIS PROJECT
───────────────────────────────────────────────────────────────────

1. SETUP FIREBASE (5 minutes)
   - Go to Firebase Console
   - Create project "ProperDisciplineApp"
   - Add iOS app (bundle: com.properProductivePigeons.app)
   - Download GoogleService-Info.plist
   - Add to Xcode project

2. INSTALL DEPENDENCIES (2 minutes)
   $ cd ProperDisciplineApp
   $ pod init
   $ pod install  # Add Firebase pods to Podfile first

3. OPEN IN XCODE (1 minute)
   $ open ProperDisciplineApp.xcworkspace
   ⚠️  NOTE: Use .xcworkspace, NOT .xcodeproj

4. BUILD & RUN (1 minute)
   - Select simulator (iPhone 14 Pro recommended)
   - Press Cmd+R
   - App launches with authentication screen

5. TEST END-TO-END
   - Sign up as Pigeon 1
   - Create Nest
   - Create Task with checkpoints
   - Open second simulator instance
   - Sign up as Pigeon 2
   - Join nest via invite code
   - See shared tasks & progress

📊 DATA STRUCTURES (Firestore)
───────────────────────────────────────────────────────────────────

Collection: pigeons/{id}
  - name, email, avatar
  - xp (integer), rank (string)
  - nestId (foreign key)
  - createdAt, lastActiveAt

Collection: nests/{id}
  - name, theme
  - pigeons (array of pigeon IDs)
  - inviteCode, inviteExpiresAt
  - createdBy, createdAt, updatedAt

Collection: tasks/{id}
  - nestId, name, description
  - taskType (personal|shared)
  - frequency (daily|weekly|custom)
  - checkpoints (array of objects)
  - createdBy, createdAt, updatedAt

Collection: task_completions/{id}
  - taskId, pigeonId, date (YYYY-MM-DD)
  - isComplete (boolean)
  - createdAt, updatedAt

Collection: streaks/{id}
  - taskId, pigeonId
  - currentCount, lastCompletionDate
  - resetDate (nullable)
  - createdAt, updatedAt

Collection: achievements/{id}
  - pigeonId, nestId
  - type, title, description
  - unlockedAt
